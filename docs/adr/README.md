Spec-level decisions (D-n) are made by David and recorded in the spec working tree (`drafts/DECISIONS.md`, `CHANGELOG.md`). An ADR here records only how this repo applies that decision. An ADR is never deleted. When a decision is replaced, mark the ADR `Superseded by NNNN`.
